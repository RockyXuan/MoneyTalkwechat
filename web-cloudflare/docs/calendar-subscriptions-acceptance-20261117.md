## 用户可见结果

- 每个来源有全年月份概览，点月份展开日期。用户明确核对过的日期范围为绿色；已有账目用圆点，不把首末消费之间自动标成完成。范围可撤销，撤销不删除账目。
- 来源包含用户要求的购物、游戏、出行和订阅服务。手机额外来源进入“更多”；抖音通过“按账号记”填写账号，之后按受保护候选中的来源身份分组。账号名不写入公开默认配置。
- 新增 `/subscriptions`；从记一笔和订阅页都能录入月/年订阅，起止月份可选往年。生成原有循环候选，经确认后按各自月份入账，不另建一套金额/账本逻辑。
- 分类未选择时保留待核对，不把订阅默认归成餐饮。未来周期不提前入账；单项历史展开最多120笔，超出提示缩小范围。已有循环记录、暂停、未纳入、待补全、删除及历史状态可查看。
- 新表单保存中锁定；未知结果保留提交标识与输入到当前浏览器会话，刷新后重开原入口可恢复重试。解释、原文与历史月份按需展开，错误保留在操作附近。
- v6备份保留来源范围及自定义来源；旧v1–v5继续读入，恢复到独立候选账本。
