# 全功能界面验收计划 · 2026-10-03

## 范围与门禁

测试当前 HTML 网页，不恢复旧原生 iOS 项目。复用既有 Playwright、金额/日期测试、真实本地 Worker/D1、演示备份及恢复接口；不新增测试依赖。参考 [多浏览器项目](https://playwright.dev/docs/test-projects)、[自动等待断言](https://playwright.dev/docs/test-assertions)、[失败跟踪](https://playwright.dev/docs/trace-viewer)。

每个功能按钮族、四页跳转、动态面板与异常结果有明确用例。同一断言在 Chromium 与 WebKit 执行；手机尺寸不冒充实际 iPhone。只在回环地址、明确 local 身份、独立临时数据库运行自动写入；禁止将完整自动恢复/退出/分类测试指向生产。生产仅已授权的标注测试、读回与可恢复清理，真实候选不修改。
