# 一次点击的分类建议 · 2026-10-11

目标：口述别称可能指旧分类，也可能是新分类。把可选结果平铺，减少下拉、返回和重复确认；保留最终入账确认与不确定状态。所有页面继续遵循能直接展示就展示、能一次完成就不拆成多次的原则。

## 复用与选择

复用当前分类 API、私有账本权限、版本号、幂等提交、候选卡片、会话草稿和备份恢复。使用原生按钮，不增加组件库、外部模型或网络请求到第三方。参考 [GOV.UK 单选规范](https://design-system.service.gov.uk/components/radios/)的互斥选项直接展示与不预选原则，以及 [W3C 按钮规范](https://www.w3.org/WAI/ARIA/apg/patterns/button/)的键盘和焦点规则。只采纳交互规则，不复制开源组件代码；现有依赖许可证与体积不变。

## 具体行为

- 精确同名且同类型的有效分类优先于别称映射。不能把明确存在的新分类合并到旧分类。
- 别称由用户明确提供，在拥有者账本分类中私有保存；只给建议，不自动入账。一次选择不自动新增永久别称；可在分类管理编辑、删除别称。
- 核对卡片显示“你说的 ××，归到哪里？”；平铺“归到已有分类（推荐）”与“新建 ××”。存在多个建议时全部呈现（最多六个），不隐藏冲突、不擅自选一个。无可靠推荐则展示常用有效分类与新建选项。
- 选择已有分类：本项立即更新，保留金额、日期、原文；显示已选择状态、附近确认反馈，可直接改选。最终绿色确认才写入账目。
- 新建分类：明确按钮触发创建，云端确认后再选到本项；同名分类复用、不重复建，停用分类不自动恢复。失败、断网、数量上限和权限错误显示在该项操作附近；不虚报成功，保留同一次提交供重试。
- 手动下拉仍作全部分类的备用入口，不能只支持推荐。手机与桌面相同行为，至少 44px 触控区，键盘可操作，颜色配合文字状态，不单靠颜色。
- 网站解析仅覆盖明确“分类某名称”、已知分类标题、已知别称的“给某人买…”语境。不把任意商品子串视为亲属或别称；复杂自由口述仍在聊天理解，并由候选 category_hint 传递建议。没有通用模型、自动学习或任意长段识别能力。

## 数据与验收

新增分类 aliases_json 可加列迁移，不修改现有账目；别称与建议使用版本 4 备份，旧版本继续恢复。推荐 ID 须同账本同类型，未解决提示不能提前生成账目。新建复用现有唯一索引，重复点击、超时与不同设备同时创建同名不产生两个分类。

集成：别称保存、类型/权限隔离、同名并发、重复请求、上限、备份完整恢复、未选建议不入账。端到端：两种浏览器、手机与桌面，推荐一次选择→逐项入账→刷新读回、新建与同名优先、多建议、手动修改、断网保留/重试、键盘操作、无横向溢出。最终运行完整 pnpm verify:release，部署后校验资产与受保护 API，并用独立候选测试账本写读回和清理；真实消费不作测试，真机验收单列。
