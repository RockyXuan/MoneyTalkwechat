## 用户可见行为

1. 每个候选有独立绿色确认按钮；只保存该项，服务器确认后显示成功再淡出、收拢。其余候选保留，已确认项可展开查看。失败不移除卡片，连点及结果不明重试不会生成重复账目；循环项展示本次展开的实际条数。
2. 桌面宽度至少 1100px 使用 460px 右栏，独立滚动且左侧仍可操作；主区域先展示批次及最近记录，再放紧凑记账表单。窄屏保持底部面板，切换尺寸不清空输入。
3. 首页与批次列表保存平台、原始购买顺序首末产品、确认进度、实际入账时间、连续确认断点与下一项。跳着确认会显示缺口，不把第一条尚未确认的记录误判为已处理；删除已入账记录时显示删除状态。
4. 未提供具体日默认只记月份，数据库存 `YYYY-MM`；明确日期或“昨天”仍保留具体日，可手动切换精度。统计日视图单列“日期未指定”，不假装为月初消费；年/月汇总、CSV 与 v3 备份保留精度，兼容旧备份。
