## 实现与复用

统计最近账单、完整账单以及手机最近记录中，日期、备注、分类、金额可直接点击，打开只编辑该项的紧凑面板。保留铅笔／分类图标的完整详情入口。沿用原生 dialog、共用表单及云端权限、完整记录 PATCH、版本冲突、操作标识重试；无新增依赖、数据库迁移或额外服务。

保存服务器确认后刷新列表及统计，已编辑字段短暂绿色反馈，键盘焦点回到该字段。未明确日期仍可只记月份；备注可清空；支出分类与收入分类独立。错误及重试位于保存附近。手机面板操作在底部，沿用键盘与安全区适配。

## 验收方法与问题修正

- 四种入口（1440px 桌面账单／统计、360px 手机账单、390px 手机最近记录）分别顺序修改备注、分类、金额、日期，读回核对另外三项、收支类型和版本，刷新再次读取。
- 异常覆盖：多余小数、清空备注、取消／Escape／放弃、并发冲突后重新加载对应字段、保存响应与操作查询同时失联后重试、重复点击、跨月移出筛选、月份切回精确日不得自动补日。
- 集成补充：实际 Worker + 隔离 D1 逐字段修改，旧版本拒绝，跨月汇总与备份读回。自动浏览器使用隔离临时数据库，真实数据不进入测试文件或 Git。
- 测试预期修正：月份账目会按日期排序、可能移出最近记录或分页；合成数据改为六条并在完整账单核对。操作查询可核实失联保存的成功，只有查询同时失败才应显示重试。没有降低产品断言。
- 视觉修正：原详情样式及原生 dialog 的上下默认定位会把单字段面板撑满；清零最小高度仍不足，已改为右上明确定位、fit-content 内容高度；360px 收支较长金额字号适配，增加文字不溢出的断言；截图等待进入动画结束。
