# 连续口述长段与长期容量闭环 · 2026-10-13

目标是对着消费 App 一段段报账，网站保留原文与顺序，逐段逐条确认，换设备仍能找到继续位置。事实：网站已有批次、绿色逐条确认、服务器回执、别称建议、平台进度和版本控制；复杂语义仍由聊天理解。自动采集与退款专项保持封存。

## 本轮交付及默认语义

- 普通文字输入去掉会截断粘贴内容的 maxlength；显示字数。一次最多 50,000 字、400 个明确项目。超过限制显示原因并保留原文，不宣称无限或任意 20 分钟录音。
- 按完整项目而非字数硬切，单段最多 10,000 字/40 项。每一字符（包括换行、分隔符与尾部文字）保留在对应云端原文，按分段顺序拼接可恢复本次完整输入。超长的单个项目不强切，明确要求在完整项目之间分段。
- 先解析整个输入再分段：相对日期固定为开始解析时上海日期；明确月份、日期和分类跨段延续；不确定时期停止沿用此前精确日；沿用日期可一键核对本段，不清除其他疑问或自动入账；别称仍平铺建议，不能自动当成永久分类。后文改口阻止前项未经核对入账，不能凭多个数字自动计算实付。
- 多段一次原子保存为云端待核对草稿，0 笔入账；失败保持原文和同次提交标识，重试只恢复同一个结果。“新一批”使用新的提交标识，相同商品、月份和金额允许表示另一笔真实消费；仍按已有流程提示同额账目并要求明确确认。备份恢复按批次身份保留这些合法相同内容，不按文本合并。
- 核对栏显示第几段/共几段；当前段确认后优先提供“继续核对第 N 段”。刷新保留进度，另一设备可从云端批次重新进入。每一平台的整段首尾与连续位置覆盖全部分段，下一段指向具体未确认草稿。
- 批次上限统一扩到 500；备份和恢复采用同一上限。备份版本 5 保存长段关联、顺序与日期锚点；旧版本 1–4 继续可读，禁止降级丢失上下文。账目/循环标识最多 50,000；现有备份上传仍有 20 MiB 文件限制，不承诺任意容量。

## 复用评估

复用既有普通 JS 解析、分类建议、批次/周期标识、幂等提交、D1 和保护账本。不引入新的模型、语音转写、第三方消费数据上传或依赖。

核查 [TC39 Intl.Segmenter](https://github.com/tc39/proposal-intl-segmenter) 的标准分句能力：它能处理语言边界，不能保证“商品金额/邮费/后文补充”仍属同一项目。因此保留项目既有明确格式拆分，增加源文本位置；未复制外部源码、未安装分句模型。

核查 [D1 JSON 官方能力](https://developers.cloudflare.com/d1/sql-api/query-json/) 与 [D1 限制](https://developers.cloudflare.com/d1/platform/limits/)：复用 json_each/json_extract 批量核对和写入，减少每笔一次查询。恢复清单保存内容摘要而非重复放入整份文字，周期标识用临时小块保存，完成校验后清理，避免大清单超过单行限制。

## 验收计划

1. 单元：原文完整、40/400/50,000 边界、跨段分类和日期、月粒度、改口、未知时期、别称、安全失败。
2. 集成：云端草稿一次全部或全部不写、重试复用、权限隔离、500 批完整平台范围/备份/恢复；120 笔循环核对与保存，记录单请求查询量，恢复周期标识后不重复生成。
3. E2E：390/1440 两尺寸、Chromium/WebKit 两引擎；连续核对、确认回执、一次进入下一段、结果页刷新、实际提交后响应丢失再重试、另一浏览器草稿不存在时从云端继续、超限不截断、旧功能全回归、按钮覆盖。无自动重试或跳过。
4. 浏览器：先 @Browser；线上需既有登录态时 Ego Lite 专用空间。实际截图只使用合成数据，直接内嵌聊天。
5. 服务：完整门禁通过后迁移与部署，版本/资源内容独立读回。独立非当前测试账本测试 500 批和长段、循环、备份恢复；真实账本内容摘要和当前选择前后相同；精确清理测试数据。
6. 真机 iPhone、国内普通网络和用户主观验收分别标为未验证，不能用模拟器代替。

本轮不启用通用 LLM 理解、不自动学习分类、不自动确认、不新增预算/债务模块。以上交付完成并有证据后，再讨论会改变方向的后续能力。

补充边界：单批草稿预测超过 120 笔时仍可查看和逐项确认，每次保存最多 120 笔；不把读取失败伪装成空账本。商品标题不全局删除“有/元/块/记录”等字；美元符号等不猜成人民币，金额留待核对。提交标识复用参照 [Stripe 官方幂等请求说明](https://docs.stripe.com/api/idempotent_requests)，复用项目现有 operations 表，不引入依赖。
