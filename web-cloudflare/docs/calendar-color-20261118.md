# 月份卡片日期进度 · 2026-11-18

范围仅为来源日历展示：每个色格对应一个真实日期；绿色仅来自用户确认核对的范围，浅黄表示尚未标记核对，灰色表示未来；具体日期有账目另以标记表示，只有月份的记录不分配到某天。点击月份可看逐日详情，点击日期可展开文字，再点关闭。范围、账目、备份和订阅数据结构不变。

复用已有日期汇总、来源范围、月份切换与日网格；参考 MDN 无障碍颜色说明（https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Understanding_WCAG/Perceivable/Use_of_color）与开源日历热图的按日格子（https://github.com/DKirwan/calendar-heatmap）。该开源实现依赖 D3，面向一般时间序列而非现有来源范围，未引入依赖，许可证和维护状态也因此未作为采用依据。

颜色示意使用虚构数据；本机预览与自动测试使用不同的独立临时数据库。本次结果见下方。

## 核对提示歧义修正
