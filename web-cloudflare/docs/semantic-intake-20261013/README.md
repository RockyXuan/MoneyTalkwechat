## 真实目标与已有基础

用户对着不同 App 连续报账，内容包含闲聊、漏字段、平台/人群切换、前文更正、原价与实付、邮费合并、循环服务以及不确定日期。目标是理解完后产生容易逐条确认的候选；不能要求用户先整理成明确格式。

现有网页已具备完整原文、云端分段、逐条绿色确认、别称平铺建议、月粒度、循环标识、平台首尾进度、金额整数分、并发和同次提交重试。复用这些能力，不重做账本、不引入自动入账、不恢复平台采集。大模型替换“理解和拆分”这一步，既有可靠记账环节继续执行。

## 复用评估

- 复用项目锁定的 Zod 4 和原生 fetch，`z.toJSONSchema` 可用，不安装转换包。模型输出必须在服务器重新校验。
- 核查 OpenAI 官方 SDK 和 structured-output 示例（MIT）及 Cloudflare 官方 AI monorepo（MIT）。旧 `cloudflare/workers-ai-provider` 仓库已归档，维护移到 `cloudflare/ai`。这些是可借鉴官方协议的实现，不能仅因为星数安装。当前只准备统一格式、提示和校验，不引入多供应商 SDK/Agent 框架，新增依赖体积 0、锁文件不变。
- 原生 Cloudflare AI binding 或供应商 HTTPS 接口只向配置的固定官方地址发送，无工具、浏览器、文件读取或数据库操作权限。密钥仅服务端 Secret；浏览器只访问本站受保护接口。
- 首版不加 AI Gateway，避免多一个默认保存提示词/输出日志的环节。以后如确有监控需求再配置禁收 payload，不能把“不记录我们的 console”冒充供应商不留存。

## 推荐处理流程

1. **收原文并固定上下文**：本次原文、消息的上海日期、用户选择的平台、当前有效分类及用户明确添加的别称。分类从当前账本服务端读取，不信任浏览器传入别人账本的映射。无默认整本历史/邮箱/账号信息/图片/音频上传。
2. **模型理解整段语义**：提取购买事实、原价/实付/合计、用途/人群、日期、循环、明确更正和未确定项。返还短引文及出现序号、金额操作数、已有分类 ID 或候选名称、未纳入内容与原因。否定、计划购买、杂谈、已经计过的还款不能混成新支出。
3. **完整性复核与程序校验**：结构、引文确实存在、项目顺序、合法日期/分类、人民币与外币、金额整数分加减及总额；缺失和歧义保留。引文存在只能证明有来源，不能证明语义/金额角色已经理解正确。模型的 confidence 不作自动保存依据。另做原文对候选的独立复核，检查遗漏/误增和后文更正；显示未归入候选的原文片段。此复核仍可能出错，不能宣称程序能发现所有漏记，人工确认和原文查看保持可用。复核是额外模型调用，费用计入总预算。
4. **展示待确认**：复用现有绿色按钮、分类建议、编辑字段和原文展开；金额来源/改口必要时直接显示，其他内容收起。未确定起始月或金额在确认按钮旁指出。分类别称一键选择不自动扩大永久规则。
5. **确认写账**：模型从来不拥有写账工具，候选为 0 笔入账；用户确认后由原接口重新校验权限、分类、版本、金额与周期。实际已保存的服务器回执驱动动画和平台进度。

长段不能沿用当前明确格式分句器先删掉闲聊再交模型。优先在所选模型安全上下文范围内完整理解；超出范围按连续原文位置分小块，保留各块来源，不靠标点假定一笔交易已完。相邻上下文及结构化状态只辅助理解，最终跨段更正需独立核对。超出模型输出上限/返回残缺/某一块失败时保持整份原文和未完成状态，不自动把部分结果当完整候选；模糊“那个不是这笔”保留待选，不猜关联。

先实测 25 道虚构口述题，另备 5 道扩展题，覆盖 8,000/20,000/50,000 字和 80/400 项，待分块任务实现后验证；所有这些都是预期答案而非模型实测。输入已有 50,000 字/400 项上限不等于大模型已经通过相同规模；模型支持范围按实测公开，超限保留原文。语音转写不是本阶段；先兼容 Typeless/系统转写后粘贴的文字，不申请麦克风或上传录音。

## 可靠性、费用与隐私设计

- 持久任务与当前云端批次分开：受保护任务状态包括 input hash、原文/分类快照版本、模型/提示版本、日期锚点、分块与结果、费用预留、实际 usage、未完成原因。只记录必要内容，在原账本权限内可清理，不公开输出个人训练集。
- 短输入可在有界请求中完成，长输入采用可恢复任务。优先核查 Cloudflare Workflows 官方能力及当期免费/步骤/存储额度后再定；不把 Workers `waitUntil` 当可靠长任务，也不默认升级付费。未建任务绑定或迁移。
- 新一段输入有新任务身份；同任务刷新/重试返回原结果。未知推理结果不得盲目重发模型调用，防止额外费用；供应商未保证推理幂等时只能说明可能已计费，预算保留按最坏情况计算。取消界面不承诺已停止远端计费。
- 调用前原子预留费用及并发名额，设服务端单次/每日/月度限制、最大输入/输出 Token；已有预留、结算失败和其他项目共享额度纳入边界。达到预算明确停 AI，手动与基础拆分仍可用。不把供应商告警邮件当硬止付；不自动跨供应商上传或升级较贵模型。
- 首次启用用一个简短可核对的面板说明接收方及具体数据；按钮附近持续显示模型接收方。真实口述仅在用户启用/点击理解的范围内发送；改供应商须重新明确。研究用例只用虚构数据。
- 不在 Worker 日志/异常/分析服务中打印原文、模型原始响应、健康/孩子信息、API 密钥或 Access 令牌；错误返回通俗原因和任务号。仅用 token 数、耗时、状态等元数据分析，公开 Git 不存真实样本。
- 自动分类“越用越懂”采用用户确认的可撤回私有规则，带来源和例外，单次选择不自动推广；冲突/同名已有分类优先尊重用户明确选择。不微调或训练模型，不上传多年历史“让模型学习”。
