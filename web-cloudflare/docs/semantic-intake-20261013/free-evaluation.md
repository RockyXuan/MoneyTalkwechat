## 免费限制与可重复工具

- `scripts/evaluate-cloudflare-free.py` 从固定人工虚构题集中选题，禁止任意用户原文/整本账本路径；只允许固定两个官方模型，拒绝其他模型、付费接收方、自动回退和自动重试。
- 凭据仅由官方 CLI 在子进程内存中读取，不打印 CLI 原始凭据输出、不加入请求正文。收尾审查发现 Wrangler 默认 logger 会写入本机日志，已在凭据子进程明确设置 `WRANGLER_WRITE_LOGS=false` / `WRANGLER_SEND_METRICS=false`，新增测试即使父进程开启日志也强制关闭；精确擦除了本轮6份有项目来源证明的日志凭据片段，正常加密登录文件未动。没有凭据上传模型/仓库，日志检查不输出凭据。请求和原始响应保存的均为虚构数据；身份令牌/邮箱/真实分类与历史不作为模型输入。
- 每次运行要求同一账户 1 小时内的实际 Free 证据及私有截图。单实例文件锁保护评测预留，所有提示轮次共享 **8,000 Neurons 保守评测预算**；使用 UTF-8 字节高估输入 token、限制输出。明确完成且有合法 usage 才按更大的供应商神经元值/列表 token 公式结算；超时/未知用量保留全部预留。模型错误也占用额度，绝不当免费重试。
- 本次保守结算约 **6,732.982**，下一题最坏预留会超过 8,000，因此调用前停止。**没有声称账户每日 10,000 已耗尽**。这不是生产硬预算系统，也不保证其他项目的剩余量；当前 Free 方案本身保证超额失败而非付费。
- 原始失败留在 `free-api-v1/`、`free-api-v2/`、`free-api-v3/`、`free-qwen38-v3/`、`free-qwen38-v4/`。36 次正式/对照请求原文快照与既有 request hash 精确一致后补存；初期 v1/v2 仅保留原始响应和提示阶段说明，不冒充完整可重放的请求快照。`free-results.json` 区分首次结果、离线修复后结果、未测题和实际耗时。
