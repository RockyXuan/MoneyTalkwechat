## 已修正的续跑可靠性

- 复用官方`wrangler whoami --json`，非交互模式先恢复现有登录，再在内存取凭据，强制禁磁盘日志/度量。恢复失败不取凭据、不打开登录页面、不发送推理；认证拒绝不是模型质量失败。
- 仅明确401/10000 Authentication error、success=false、result=null的完全拒绝视为未进入推理；其他错误不据此释放预算。
- 完整HTTP超时回执用量未知，当日保留满额。对本次确实收到的Cloudflare终止错误，按回执UTC日预留；过去UTC日已明确终止的失败不永久占新日预算。客户端断网、没有终止回执、时间无效/缺失或其他不确定结果继续保留跨日预留，不自动重发。历史2个超时文件补充的是首次人工编辑前的原始文件mtime（写文件发生在终止回执之后），明确标注来源；请求、错误正文、秒数、hash不改动，不伪装为供应商usage或精确供应商时间。
- 报告保留所有请求，但只有HTTP200、成功且实际模型身份一致才进入模型答题计数；认证/服务失败保持未测和错误证据，不计入准确率失败或通过。输出截断、语义错误仍算未通过。
- 响应模型不一致立即停止后续推理。既有文件锁、预算预留、固定端点、无工具权限和单次提交身份继续执行。
