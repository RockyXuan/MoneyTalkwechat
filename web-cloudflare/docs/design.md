# MoneyTalk 首版设计规范

设计来源为用户批准的 C1/M1/M2/G1，基准图片保存在 design-reference。图片是排版与视觉参考，账目金额和图表必须由真实统计响应计算。

| 基准 | 使用范围 | 有意校正 |
|---|---|---|
| C1 | 深蓝侧栏、浅色工作区、三张收支卡、图表/排行、快捷记账、最近账单 | 增加可用的月/季/年选择；最近账单按真实日期排序，不把工资硬插到前六笔 |
| M1 | 手机记一笔/账单/统计/我的四页 | 去掉语音、订阅等未实现入口；只有一个页面标题 |
| M2 | 常用分类胶囊、原卡片内展开 | 收入分类独立；长名称收起省略、展开完整换行；分类颜色统一 |
| G1 | 三种图表切换与信息层级 | 无假数据；月按日、季/年按月；最后一个日期刻度保留；折线不平滑、不累计 |

## 布局与视觉

小于 768px 为底部四项导航；768–1439px 为紧凑侧栏、快捷记账抽屉；1440px 起为完整工作台。主内容限制最大宽度。手机默认记一笔，桌面默认统计；显式 URL 始终保留目标页。

桌面侧栏约 208px、主背景 #F5F8FF、蓝色操作 #2467E8，白色卡片配浅边线和 12–16px 圆角。使用系统字体和表格数字。手机金额和备注可直接输入；文字输入至少 16px，主要操作与分类有至少 44px 触控区域；小屏幕可滚动，底部留出安全区。

分类色板保存到分类记录：餐饮蓝、购物橙、交通绿、生活紫、其他灰。收入默认绿色系。图标与名称同时出现，不仅依赖颜色；同一分类跨月份、排行和图形不换色。

## 交互状态

记账：空金额 → 输入 → 保存中锁定 → 服务器确认 → 清空已提交草稿并刷新最近记录。失败保留；不明确的结果保留原提交标识。新建、编辑和快捷记账共用表单，编辑有记录版本和删除入口。

删除确认包含金额、日期、分类；之后可撤销或进入回收站恢复。冲突不静默覆盖，明确要求载入最新记录。

加载、失败、空账本、只有收入和恢复未完成分别呈现；加载失败不显示 0。图表旁有分类排行、可展开金额表；手机轻触图形显示金额，点击图例/排行进入对应账单。饼图不直接跳页，避免轻触后无法看清提示。

备份：选择 → 预览 → 候选账本写入/进度 → 完整核对 → 显式切换。损坏备份没有写入按钮。账本切换不删除原账本。

## 固定演示数据与还原验收

使用 shared/demo.js：2026-09，61 笔，支出 324800 分，收入 1800000 分，结余 1475200 分。分类支出 124000 / 96800 / 52000 / 32000 / 20000 分，合计严格一致。

截图尺寸为 390×844、1440×900、1920×1080，另检查 360、430、768px。手机表单中的 35.00 与午餐为未保存演示输入，单独标明草稿。以布局、颜色、间距、控件状态和内容可读性逐项对照；没有宣称整张生成图与网页像素完全相等。系统字体渲染、图表日期和值、触控热区、可用操作与安全提示会产生必要差异。

真实 iPhone 键盘、Safari、安全区、缩放和屏幕阅读器仍需真机验收，桌面缩窄不替代真机。
