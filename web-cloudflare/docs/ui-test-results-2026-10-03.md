## 重点异常证据

- 空/零/负/三位小数/超限/错误千分位/非数字金额、未来日期均不写入，保留输入。
- 双击保存只产生一笔。真实本地服务器已写入而浏览器丢失响应时，使用原提交标识读回成功；未写入的网络失败可重试且不重复。
- 两个版本修改同一条记录时，过期版本收到冲突；用户明确载入最新内容后再编辑。
- 删除取消、移入回收站、撤销、恢复、51 条以上回收站分页与真实统计对齐。
- 完整/筛选 CSV 下载读取实际字节；JSON 下载与账本数量一致；损坏文件拒绝；恢复先预览、写独立候选、核对、明确切换，同备份复用已校验候选。
- 月/季/年与柱/线/饼切换总额相同，图例/排行下钻正确；没有支出和只有收入都不绘制假饼图；数据列表可阅读。
- 跨两月循环项精确生成两笔，两月日期与整数分金额读回一致。未知起始月只保存草稿，不生成支出；暂停/恢复、草稿取消删除/确认删除、同额确认、失败核对、文字会话草稿均覆盖。
- 初始化/统计/文字列表失败有明确错误和重试，统计失败不会显示为零消费。

## 可重复运行与数据隔离

在 `web-cloudflare` 目录运行：

```sh
pnpm verify
pnpm test:ui
pnpm test:ui:coverage
```

首次在新机器运行可执行 `pnpm exec playwright install chromium webkit`。Mac 沙箱禁止回环端口时，在允许 localhost 的开发终端运行；不能把 `listen EPERM` 当作产品问题。

自动测试只允许 `http://127.0.0.1:8791` 和明确 local 身份；启动器每次新建临时 D1、应用本地迁移、创建虚构账本。默认拒绝复用已占用的服务器，不使用原开发账本或生产。停止时只终止自己创建的进程组，并清理自己的临时数据目录。

测试工具自启动另跑 8 个核心场景通过。收尾发现 Playwright 默认强制结束父进程会遗留独立进程组，改用官方 `gracefulShutdown` 配置传递正常停止信号；之后 Chromium/WebKit 两项焦点场景从空端口自动启动到退出共 5.9 秒，通过且 8791 已释放。原遗留的本任务两个虚构数据库目录已精确清理；没有终止原 8787 开发服务。

完整 JSON 报告为 `test-results/ui-results.json`，可打开的 HTML 报告为 `test-results/ui-report/index.html`，操作覆盖报告为 `test-results/ui-control-coverage.json`。报告、截图、跟踪不提交 Git；测试源与计划提交。每项点击覆盖随测试结果附带；新增事件操作未覆盖时覆盖检查失败。

已从完整报告提取 390/1440px 的两引擎四页截图到 `test-results/acceptance-screenshots/`，人工查看 WebKit 记账、账单、统计、设置及桌面工作台：深蓝侧栏、蓝白手机界面、底栏、分类颜色与演示金额一致。此检查没有宣称逐像素 1:1 或主观真机手感已验收。
