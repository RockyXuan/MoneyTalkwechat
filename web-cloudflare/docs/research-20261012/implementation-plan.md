# 本轮落实与验收

## 实施

- 账单列表显示搜索、收支类型、分类、自定义期间标签，一次点击仅取消该条件；切回“全部”保留已选分类；零结果仍显示查询上下文。
- 当前期间按钮：账单回本月，统计按当前视图回本月/本季/本年；清除旧自定义期间、归零分页，但保留搜索/分类条件。
- 账单完整详情提供“再记一笔”：重新读取受权限保护的原记录；复制可用分类、金额和备注到独立新草稿，日期为当前月份，清除旧 id/version/操作标识。停用分类必须重新选择，主页面已有草稿不受影响。服务器确认前不写账，保存使用现有幂等接口。
- 用户已选择 B：手机六平台按钮保持固定顺序，显示未记录/待核对/已处理状态；一次切换仅展示该平台的完整卡片，桌面仍全部展示。选中状态跟页面会话保持，切换不改账。保留首尾、连续边界、分类、历史、其他来源与加载失败状态。用短淡入说明平台切换，尊重减少动画偏好。
- 不增加依赖。复用原生 dialog、现有表单/分类按钮、受保护 Worker 接口、已有平台聚合与 CSS。竞品学习仅限模式，没有拷贝品牌素材/开源代码。MIT Actual 和 GPL Cashew 均不引入软件包，架构/体积/许可边界不适合整体迁移。

## 验收用例

集成：读取原记录后创建新记录，原记录金额/备注/版本保持，幂等重试同 id，跨用户读取拒绝。沿用现有非法金额、月精度、停用分类、权限与统计回归。

E2E（Chromium＋WebKit，手机 390 与桌面 1440）：

1. 多条件筛选逐个取消，搜索包含特殊文字正确转义；零结果仍看见条件；刷新保留剩余条件；切“全部”不清分类。
2. 旧月份回当前，分页与自定义期间重置、其他条件保留；统计季度/年度仍保持视图。
3. 再记一笔先显示独立草稿，关闭不写账；保存后新增一条，原记录不变，已有主草稿保留；连点不重复；分类停用后要求选择；未保存修改关闭保护。
4. 手机六平台固定按钮与状态，切换完整首尾/历史/分类，主草稿保留；其他来源可到；桌面六卡不折叠；360/390/430 下无横向溢出、触控区域够用；减少动画可用。

最终执行 pnpm verify:release，全量成功才发布。发布后核对版本与匿名身份保护，独立候选账本可逆写/读/清理，真实账本前后保持。真机、国内网络和用户最终验收明确分开。
