# 极简记账 UI 重构计划 — 1:1 还原 GPT5.5 模板

## 概述

按照用户提供的 GPT5.5 UI 模板图（5张）和《极简记账 UI 设计需求.docx》中的设计规范，1:1 还原全部 5 个页面。核心风格：苹果 iOS 风、极简、高级灰白背景、蓝色主色(#2F7BFF)、大圆角卡片、轻阴影、高留白。平台：mobile 微信小程序。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 主色 | `#2F7BFF` (苹果蓝) | docx 明确指定 |
| 页面背景 | `#F5F7FB` | docx 指定 |
| 卡片 | 白色 #FFFFFF, 圆角 32rpx, shadow-card | docx 卡片系统 |
| 字体 | PingFang SC / -apple-system | iOS 原生风格 |
| 布局间距 | 页面边距 30rpx, 模块间距 24-32rpx | docx 间距规范 |
| TabBar | 浮动圆角样式, active 蓝 inactive 灰 | 模板图样式 |
| 设计来源 | 5 张 UI 模板图 + docx 规范 | 唯一视觉标准 |

## 是否有原型设计

是（设计引导已开启）。但用户已提供完整 UI 模板图，原型阶段将直接基于模板图生成 HTML 原型，再进入代码开发。

## 实施步骤

1. **保存 UI 模板图到项目 + 更新 CSS 变量系统** — 将 5 张模板图复制到 `assets/ui-templates/`，按 docx 规范更新 `src/app.css` 全局色值、字体、间距、阴影变量
2. **原型设计** — 加载 design-canvas 技能，按 5 张模板图生成 mobile 原型 HTML，完成后提示用户验收确认
3. **重构记一笔页面** — 1:1 还原模板图 Page1 的所有区域：标题栏/日期筛选/输入卡片/分类 chips/智能记账按钮/最近记录/双列辅助卡片/提示条（`src/pages/index/index.tsx`）
4. **重构订阅 + 账单页面** — 1:1 还原 Page2 订阅管理 + Page3 账单页面（`src/pages/subscriptions/index.tsx` + `src/pages/bills/index.tsx`）
5. **重构统计 + 我的页面** — 1:1 还原 Page4 统计 + Page5 我的页面，包括浮动 TabBar 样式（`src/pages/stats/index.tsx` + `src/pages/profile/index.tsx`）
6. **TabBar 重构 + 图标更新 + pnpm validate** — 实现 docx 规范的浮动圆角 TabBar，更新图标，执行 validate 修复所有 error
7. **编译检查与验收** — 执行 `pnpm build`，确认全端编译通过，对照模板图逐页检查一致性

##### @page(/) 记一笔

**核心职责**：一句话智能记账 + 最近记录查看
**访问路径**：TabBar 直达
**布局**：页面标题栏 → 日期筛选栏 → 输入卡片 → 分类 chips → 智能记账按钮 → 最近记录卡片 → 双列辅助卡片 → 底部提示条
**列表项字段**：分类图标 / 描述 / 金额 / 日期
**状态**：
- 空态：最近记录显示"暂无记录，去记一笔 >"
- 加载态：智能记账按钮 loading "识别中..."
- 错误态：识别失败提示"没识别出来，可以换个说法"

| 日期选择器 | 点击 | 弹出日期选择 | — | — |
| 输入框 | 输入 | 实时字数统计 | — | 0/200 |
| 分类 chip | 点击 | 选中/取消选中分类 | category | 选中态蓝色填充 |
