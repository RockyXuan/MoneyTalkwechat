# 极简记账 — UI 设计规范与项目知识库

> 本文档沉淀了项目全生命周期的设计规范、UI 原型参考、经验教训和用户偏好，作为后续开发的唯一视觉标准。

---

## 一、项目概述

- **产品名称**：极简记账
- **定位**：AI 驱动的极简记账小程序，一句话记账 + 订阅管理 + 智能统计
- **目标平台**：微信小程序 / 抖音小程序 / H5（Taro 跨端）
- **技术栈**：Taro 4 + React 18 + NestJS 10 + Supabase (PostgreSQL)
- **设计理念**：蓝白极简风、大圆角卡片、蓝色渐变主视觉、AI 融合体验

## 六、设计经验与踩坑记录

### 6.1 用户反复拒绝的设计方案

| 方案 | 主色 | 用户反馈 | 失败原因 |
|------|------|----------|----------|
| 苹果风 | `#007AFF` | "太丑了" | 配色太冷硬，缺乏温度 |
| 暖棕风 | `#B8643A` | "太丑了" | 色调偏老气，不适配极简记账 |
| 蓝紫渐变 | `#2F7BFF→#5B9BFF` | "不是一个东西" | 色值偏差太大，与UI模板图不匹配 |

### 6.2 关键经验教训

1. **色值不能自行发挥**：UI 模板图的实际主色是 `#4080FF`/`#2979FF`/`#257BFF`，不同页面有细微差异，不能用一个 `#2F7BFF` 统一糊弄
2. **圆角大小必须精确**：卡片 16px，标签 20px（药丸），按钮 28px（全宽）/ 12px（常规），排名徽章 10px
3. **阴影是视觉层次的关键**：订阅卡片 `#000000 0.03`，统计卡片 `#00000008`，总支出卡片 `#2979FF33`（蓝色调阴影）
4. **页面背景不同**：记一笔/订阅 = `#F8F9FC`，账单 = `#FFFFFF`，统计 = `#F5F7FA`，我的 = `#F8F9FA`
5. **分类图标必须有颜色背景**：不是裸图标，是彩色圆形/圆角方形图标（40px 圆形 或 18px 圆角 4px 方形）
6. **药丸标签 vs 方形标签**：首页分类用圆角 20px 药丸，订阅筛选用圆角 8px 方形（白底蓝底切换），账单筛选用圆角 20px 药丸

### 6.3 技术实现注意事项

1. **Tailwind 任意值限制**：禁止 `w-[340px]`、`text-[14px]`、`p-[16px]` 等带 px 任意值，Taro pxtransform 会导致跨端不一致
2. **Taro 原生 Text**：垂直排列必须加 `block` 类，否则 H5 白屏
3. **Taro 原生 Input**：必须 View 包裹，样式放外层（H5 端 Input 是 inline 元素）
4. **Fixed + Flex 布局**：必须 inline style，Tailwind fixed+flex 在 H5 失效
5. **lucide-react-taro 图标**：className 的 text-\* 不会改变 stroke/fill，用 `color` prop 控制颜色
6. **组件库优先**：按钮/输入框/卡片/弹窗等必须用 `@/components/ui/*`，禁止 View/Text 手搓

### 6.4 用户偏好总结

1. **1:1 还原 UI 模板图**：不要自行发挥，用户说"这个作业要怎么给你抄，你才能抄得明白"
2. **蓝白极简风**：用户多次拒绝其他风格，最终选定 GPT5.5 生成的蓝白风格
3. **AI 融合体验**：智能记账、订阅识别、AI 洞察、AI 记忆偏好是核心差异化功能
4. **微信生态**：微信绑定聊天记账、公众号推送是重要功能
5. **订阅管理是刚需**：ChatGPT Plus / iCloud 等数字订阅追踪是高频场景

## 七、GPT 输出建议（如果需要重新生成 UI 模板）

如果需要让 GPT 重新生成 UI 模板图，建议按以下方式指导 GPT 输出，才能让开发者更好地还原：

### 7.1 色值统一

**问题**：5 张图中主色不统一（`#4080FF`/`#2979FF`/`#257BFF`/`#4285F4`），导致实现时无法确定唯一正确值。

**建议**：让 GPT 输出时明确指定「全局主色统一为 #2979FF」，所有页面保持一致。

### 7.2 标注间距和字号

**问题**：GPT 图片是位图，无法精确获取间距和字号。

**建议**：让 GPT 同时输出一个「设计标注 JSON」，格式如下：
```json
{
  "page": "记一笔",
  "background": "#F8F9FC",
  "sections": [
    {
      "name": "日期选择区域",
      "background": "#FFFFFF",
      "borderRadius": 16,
      "padding": { "top": 16, "right": 16, "bottom": 16, "left": 16 },
      "margin": { "top": 0, "right": 16, "bottom": 12, "left": 16 },
      "elements": [
        {
```
